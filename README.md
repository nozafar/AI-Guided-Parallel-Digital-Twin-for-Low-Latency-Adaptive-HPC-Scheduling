# AI-Guided Parallel Digital Twin for Low-Latency Adaptive HPC Scheduling

## Research Problem
High-Performance Computing (HPC) clusters manage highly complex, varied, and interdependent workloads. Scheduling these workloads effectively to minimize latency (waiting time, response time, makespan) while maximizing resource utilization (CPU, GPU, memory) is an NP-hard problem.

## Research Gap
Traditional heuristic-based schedulers (e.g., FCFS, Shortest Job First, EASY Backfilling) cannot dynamically adapt to changing workload distributions and complex resource topologies. While AI-based schedulers exist, they are difficult to safely train and evaluate on live clusters. 

## System Architecture
We propose an AI-guided Digital Twin architecture:
1. **Digital Twin Simulator**: A SimPy-based discrete-event simulator representing cluster nodes, GPUs, memory, and executing jobs.
2. **AI Predictor**: An XGBoost model predicting actual workload behavior (e.g., runtime estimation) from user-submitted requests.
3. **RL Scheduler**: A PPO-based Reinforcement Learning agent that learns optimal scheduling decisions by interacting with the Digital Twin.

## Methodology
- **Dataset**: A synthetic HPC workload generator mimicking real production behavior (e.g., Alibaba Cluster Trace), capturing realistic resource overestimation, burst arrivals, and heterogeneous job types.
- **Evaluation**: The proposed AI scheduler is benchmarked against FCFS, SJF, and Priority scheduling inside the digital twin.
- **Metrics**: Average waiting time, makespan, and resource utilization.
